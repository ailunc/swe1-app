# Continuous integration implementation plan

**Goal:** Run the homework checks on GitHub pushes and pull requests, report coverage, and deploy successful main builds to the existing Elastic Beanstalk environment.

**Architecture:** Travis runs Black, flake8, and the existing Django tests under coverage.py. Coveralls receives the report. The Elastic Beanstalk deployment provider updates swe1-app-env in us-east-2 only for main builds. GitHub requires the observed Travis PR check before merging.

**Tech stack:** Python 3.13, Django 5.2, Travis CI, Black, flake8, coverage.py, Coveralls, AWS Elastic Beanstalk.

## Constraints

- Retain the existing polls behavior and database.
- Use the existing AWS resources and credit budget.
- Store credentials only in protected service settings; never in Git.
- Give slurpysalmon Write access as required by the assignment.
- Keep commits and documentation under the repository's existing identity.

## Verification focus

- Formatting and lint violations must fail CI.
- A new PR must start a Travis check automatically.
- PRs and non-main branches must not deploy.
- The deployed application version must match a successful main build.
- Branch protection must name the actual Travis PR check.
